## 🔴 КРИТИЧНЕ (блокує продажі / канали)

### 1. Реальні фото — 96% плейсхолдерів (7043 з 7312)
- **Проблема:** справжні фото лише у 269 товарів. Це ЖОРСТКИЙ ШЛЮЗ: Google Merchant Center і Rozetka **відхиляють** товари з плейсхолдерами; блокує Google Shopping, Rozetka, безкоштовні локальні лістинги, динамічний ремаркетинг Meta.
- **Що зробити:** [Ти] написати постачальникам — попросити фотоконтент (Rozetka приймає фото постачальника, не обов'язково власне) → розблокує брендові позиції безкоштовно. Далі — власна фотосесія власного/безбрендового (наживка, монтажі, макуха).
- **Готово для тебе:** `data/photo_priority_ONLINE_20260717.csv` (топ-200 під онлайн, тільки те що відправляється), `data/photo_plan_by_shelf_20260717.csv` (по полицях). ~100 знімків = основна виручка.
- **Технічно:** знімати мін. 1000×1000 (Google з 31.01.2027 вимагатиме 500×500); Rozetka — 3-6 ракурсів, головне фото без упаковки «1 в 1».
- **[Я]** заллю на сайт, щойно фото з'являться (механізм `upload_horoshop_images.py` перевірено).

### 2. Аналітики немає ЖОДНОЇ (сайт сліпий)
- **Проблема:** ні GA4, ні GTM, ні Meta Pixel — усі 3 скриптові слоти порожні. Неможливо виміряти трафік, джерела, конверсію; блокує ремаркетинг.
- **Що зробити:** [Ти] створити GA4 → дати `G-XXXXXXX`; створити Meta Pixel → дати ID. **[Я]** вставлю за 5 хв (місця готові: `extra[script_in_head]` + нативне поле `extra[facebook_conversion_marker]`).

### 3. Посилання на соцмережі — порожні заглушки
- **Проблема:** `instagram.com/`, `tiktok.com/` ведуть на головні платформ, не на ваші акаунти.
- **Що зробити:** [Ти] дати URL Instagram і TikTok → **[Я]** вставлю.

### 4. Фіди для маркетплейсів зламані
- **Проблема:** `render_facebook.py:39` хардкодить неіснуючий домен `vse-dlya-rybalky.com.ua`, усі 8751 товарів → `no-image.jpg`. У цьому вигляді Google/Rozetka відхилять усе.
- **Що зробити:** **[Я]** перегенерувати з правильним доменом + реальними image-URL — коли дійдеш до Rozetka/Google (раніше немає сенсу, застаріють).

### 5. Пароль адмінки — змінити (пересторога після вірусу)
- **Проблема:** поки шкідливе розширення Chrome було активне, могло перехопити пароль.
- **Що зробити:** [Ти] змінити пароль Horoshop + завершити всі сесії.

### 6. 0 онлайн-замовлень за весь час
- **Проблема:** магазин технічно робочий, але онлайн не продає — бракує ТРАФІКУ (офлайн ~10.9 млн грн/3 роки).
- **План:** `docs/MARKETING_PLAN_2026.md` (детально). Коротко: аналітика → фото → TikTok (працює вже) → Rozetka/Google (після фото).

## 🟡 ВАЖЛИВЕ

### 7. AI-сміття у значеннях характеристик
- **Проблема:** частина текстових характеристик має галюцинаційні значення від кривого AI-збагачення. Приклад (виправлено): «Передаточне число» = «Реалістичне припущення»/«Залежить від моделі» замість 5.2:1 → фільтр видалено. **Ймовірно є ще** в інших характеристиках.
- **Що зробити:** **[Я]** пройти значення всіх текстових характеристик, знайти фрази-маркери («приблизно», «залежить», «реалістичне», «оптимальне», «не вказан», «недоступно») і почистити (очистити або виправити). ~1-2 год роботи.

### 8. Мертві ghost-значення у фільтрі Бренд
- **Проблема:** ~40 брендів у фільтрі мають лічильник >0, але 0 товарів (Daiva, DIWA, SPRINTER, POLO, Titan...) — сталий індекс від прихованих/розпроданих товарів. Захаращують випадаючий фільтр.
- **Що зробити:** Horoshop прибере при переіндексації сам; або **[Horoshop]** попросити примусову переіндексацію каталогу. Через товари не виправляється (їх немає).

### 9. «Готові набори» — опублікувати
- **Готово:** 4 набори з реальних продажів (`data/ready_sets_20260717.csv`): Короп-Старт 2350, Фідер 1660, Початківець 1250, Боєкомплект наживки 340 грн.
- **Що зробити:** [Ти] підтвердити ціни (знижка 5-10%) + 1 фото на набір → **[Я]** створю категорію «Готові набори» + заведу товари. Вищий чек + контент для TikTok.

### 10. Перенос на новий ноут (автосинк вимкнений)
- **Проблема:** задачі синку залишків/цін і замовлень→УкрСклад вимкнені з 11.06. Поки збіг є, але дрейф накопичуватиметься від офлайн-продажів.

### 11. Точкові прогалини характеристик
- **Проблема:** характеристики повні на 85-90%, але «Довжина»/«Тест» відсутні у частини вудилищ.

## ⛔ ОБМЕЖЕННЯ ПЛАТФОРМИ (без Horoshop/зміни тарифу не виправити)

- **Фільтр по Довжині/Тесту/Типу вудилища — НЕМОЖЛИВИЙ.** Ці характеристики — вільний текст, Horoshop у фільтр пускає лише параметри-довідники. Конверсія в довідник = редагування шаблону 381, яке ламає товари (SQL FK-баг). **[Horoshop]** — можливо, підтримка зробить це на їхньому боці.
- **Об'єднання варіантів товару** (напр. одна картка з вибором довжини) — той самий баг шаблону 381.
- **Масовий імпорт зв'язків/аксесуарів** — API недоступне на тарифі (409). Тому аксесуари зроблено через опис.
- **Форма створених товарів** віддає 503 через HTTP — редагуються лише через pricelist-імпорт по артикулу.
