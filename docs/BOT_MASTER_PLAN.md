## 1.5. UX-АНАЛІЗ І ПЕРЕРОБКА (29.07)

### Що було не так зі старим меню

```
[📊 Статистика] [⏭ Наступний товар]
[🔄 Запустити синхронізацію]
[📥 Оновити систему та перезапустити] [🛑 Зупинити всі процеси]
```

| # | Проблема | Наслідок |
|---|---|---|
| 1 | **Немає найголовнішого — замовлень** | те, за що платять гроші, недоступне з меню |
| 2 | **Змішані аудиторії** | Марина бачить «Зупинити всі процеси» поруч зі статистикою |
| 3 | **Небезпечні дії без підтвердження** | один випадковий тап — і процеси вбиті / бот перезапущений |
| 4 | **«⏭ Наступний товар»** | незрозуміло, що це модерація AI-описів |
| 5 | **«🔄 Запустити синхронізацію»** | незрозуміло *що* синхронізується; 75 сек тиші; пише на живий сайт |
| 6 | **Немає пошуку товару** | найчастіша дія в магазині взагалі відсутня |
| 7 | **Немає /help** | новий користувач не розуміє, що вміє бот |
| 8 | Довгі повідомлення | Telegram ріже >4096 символів — статистика могла не дійти |

### Нове меню

**Головне (щоденне, для Марини):**
```
[🛒 Замовлення]     [🔎 Знайти товар]
[📸 Що фоткати]     [📊 Статистика]
[⚙️ Ще]
```

**⚙️ Ще (технічне, для Max):**
```
[🩺 Перевірка системи] [🏆 Топ продажів]
[⚠️ Закінчилось з топу] [🤖 AI-описи]
[🔄 Синхронізація]
[📥 Оновити бота] [🛑 Стоп процеси]
[⬅️ Назад]
```

### Принципи, за якими переробив

1. **Гроші — на перший екран.** Замовлення й фото (те, що розблоковує продажі) — у головному меню.
2. **Небезпечне — за двома кроками.** Технічні дії сховані в «⚙️ Ще», а руйнівні (оновлення, стоп) ще й вимагають підтвердження «✅ Так / ✖️ Скасувати».
3. **Один тап — одна зрозуміла дія.** «Синхронізація» більше не одна кнопка на 75 сек: тепер вибір із трьох — залишки / замовлення / повний цикл, з поясненням, що коли потрібно.
4. **Бот говорить людською мовою.** Не «ai_draft», а «Чекають перевірки». Не «Опубліковано: 0», а реальні метрики магазину.
5. **Не мовчить.** Перед довгою операцією — «⏳ Перевіряю…», після — результат або зрозуміла помилка.
6. **Прощає помилки.** Надіслали фото без артикулу — бот сам запитає. Надіслали текст — сам вирішить, це артикул чи пошуковий запит.
7. **Довгі відповіді ріжуться** на частини по 3900 символів.

### Головна нова механіка: фото з телефона → одразу на сайт

Найдорожча проблема магазину — 96% заглушок замість фото, це блокує Rozetka
і Google Shopping. Тепер:

```
Марина фоткає товар → надсилає в бот, у підпис пише артикул
   → бот заливає на сайт (замінюючи заглушку)
   → у відповідь показує картку товару з посиланням
```

Без підпису бот сам спитає артикул. Кнопка «📸 Що фоткати» показує чергу —
топ товарів без фото за виручкою, з лічильником прогресу.
