# Telegram-бот керування товарами

Бот для магазину **vsedliarybalky.com.ua**: статистика каталогу, останні додані товари,
пошук, картка товару, зміна ціни/залишку. Працює локально (без VPS), нуль зовнішніх
залежностей окрім `requests`.

## Крок 1 — створити бота (це робиш ТИ, 1 хвилина)

1. У Telegram відкрий **@BotFather**.
2. Надішли `/newbot`, дай ім'я (напр. «Vsedliarybalky Admin») і username (напр. `vsedliarybalky_admin_bot`).
3. BotFather дасть **токен** виду `1234567890:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

## Крок 2 — дізнатись свій Telegram ID

Напиши будь-що боту після запуску — він відповість твоїм `id`, або скористайся @userinfobot.

## Крок 3 — конфіг

```
cp src/telegram_bot/config.example.json src/telegram_bot/config.json
```
Встав токен і свій id:
```json
{"token": "1234567890:AAE...", "allowed_user_ids": [123456789]}
```
Якщо `allowed_user_ids` порожній — бот працює для всіх (не рекомендовано; спершу дізнайся свій id
через /whoami, потім впиши).

## Крок 4 — запуск

```
python src/telegram_bot/bot.py
```
Бот лишається запущеним у терміналі й опитує Telegram (long-polling).
Щоб працював постійно — залиш вікно відкритим або додай у Планувальник завдань Windows
(запуск `python D:\FISH\fish-sync\src\telegram_bot\bot.py`).

## Інтерфейс — КНОПКИ

Надішли `/start` — зʼявиться меню з кнопками:

| Кнопка | Дія |
|---|---|
| 📊 Статистика | усього товарів, у наявності, групи, сер. ціна |
| 🌐 На сайті | жива к-сть товарів на сайті (запит до Horoshop) |
| 🆕 Останні додані | нові товари |
| ⚠️ Малий залишок | товари, що майже закінчились |
| 🔎 Пошук / 📦 Картка | знайти товар за назвою/артикулом (бот попросить ввести) |
| ✏️ Змінити ціну / залишок | оновити товар на сайті (бот попросить `артикул значення`) |
| 🔄 Синхр. ціни/залишки | вивантажити свіжі ціни/наявність УкрСклад → сайт (безпечно) |
| 🧾 Забрати замовлення → списати склад | зчитати нові замовлення з сайту і **списати** продані товари з залишків УкрСкладу + видаткова накладна |

`/whoami` — показує твій Telegram ID (щоб замкнути бота на себе).

## Примітки

- Дані для `/stats /search /recent /product /lowstock` беруться з локального `data/products.json`
  (швидко, без навантаження на сайт).
- `/setprice` та `/setstock` пишуть на сайт через безпечну форму (зберігають усі інші поля).
- Товари, створені в новому редакторі (стара форma віддає 503), для запису недоступні —
  бот про це чесно повідомить.
- Доступ до Horoshop бот бере з `D:\FISH\fish-sync\.env` (ті самі логін/пароль, що й пайплайн).
