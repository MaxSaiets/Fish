# Як розгорнути систему на новому ноутбуці

Ця інструкція створена спеціально для того, щоб ви могли перенести весь проект на новий ноутбук і налаштувати його буквально за пару кліків.

## Крок 1. Перенесення файлів та бази
1. На старому комп'ютері знайдіть папку з проектом (зазвичай `D:\FISH\fish-sync`). Скопіюйте її на флешку чи в хмару.
2. Вставте цю папку на новий комп'ютер у ТЕ Ж САМЕ місце: `D:\FISH\fish-sync`.
3. Впевніться, що у папці `fish-sync` є файл **`.env`** (він прихований, тому перевірте, чи ви його скопіювали. Там зберігаються паролі до сайту та Telegram).
4. Перенесіть або встановіть **УкрСклад7** на новий комп'ютер. Шлях до бази має залишатись стандартним: `C:\ProgramData\UkrSklad7\db\Sklad.tcb`.

## Крок 2. Встановлення Python
1. Завантажте Python з офіційного сайту (рекомендовано версію 3.11).
2. При встановленні **ОБОВ'ЯЗКОВО** поставте галочку "Add Python to PATH" внизу вікна інсталятора.

## Крок 3. Встановлення залежностей (бібліотек)
Відкрийте термінал (натисніть Win, напишіть `cmd` або `powershell`) і виконайте наступні команди по черзі:
```powershell
# Встановлення потрібних бібліотек Python
pip install fdb requests openpyxl xlwt lxml python-dotenv rapidfuzz
pip install playwright aiogram==3.13.1 google-generativeai schedule

# Встановлення прихованого браузера для авто-публікації товарів
playwright install chromium
```

## Крок 4. Автоматизація (Планувальник завдань)
Останній і найпростіший крок — змусити систему працювати самостійно, без появи чорних вікон (CMD) на екрані.

1. Відкрийте папку проекту `D:\FISH\fish-sync`.
2. Натисніть правою кнопкою миші на файл `setup_task_scheduler.ps1` і виберіть **"Run with PowerShell"** (або "Відкрити за допомогою PowerShell").
   - *Якщо система попросить права адміністратора — погодьтесь.*
3. Скрипт автоматично створить 4 фонові задачі:
   - `FishSyncStock` — оновлення залишків щогодини.
   - `FishSyncOrders` — завантаження замовлень з сайту щогодини.
   - `FishSyncFullPipeline` — повний цикл (з генерацією описів AI та додаванням нових товарів), що працює раз на день.
   - `FishSyncServer` — веб-сервер для Розетки/Facebook, що запускається при старті Windows.

**ВСЕ!** Система повністю налаштована.

## Крок 5 (для перевірки)
- Якщо ви хочете перевірити, чи все працює, відкрийте свій Telegram і зайдіть у бот.
- Натисніть кнопку **"🔄 Запустити синхронізацію"**. Бот самостійно запустить скрипт, і через хвилину надішле вам звіт.
