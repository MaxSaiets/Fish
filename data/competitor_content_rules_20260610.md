# Еталонні правила контенту (з аналізу конкурентів, 2026-06-10)

Джерела: flagman.ua, fishunter.com.ua, fishingstock.ua, world4carp.com.ua, goldencatch.ua, horoshop.ua/blog.

## 1. Назви товарів (підтверджено — наш формат правильний)
Патерн: `{Тип} {Бренд} {Модель/Серія} {Довжина}м {Тест}г` 
Приклади конкурентів:
- "Спінінг Flagman Bonus 83H 2.51м 10-45г"
- "Спінінгове вудлище Azura '24 Fortran 76L 2.29м up to 16г"
- "Котушка Shimano Nexave 4000HG FI"
- "Гачок Hayabusa H.ISE147BN"
- "Бойли плаваючі Krill (криль)"

## 2. Описи товарів — ЕТАЛОН (fishunter/world4carp стиль)
Структура 4-5 коротких абзаців, КОЖЕН про конкретний аспект, БЕЗ води:
1. **Позиціонування серії/товару** — для кого і для чого ("бюджетна серія універсальних
   спінінгів зі швидким строєм і прекрасним балансом" / "створювався для важких умов лову —
   змагань, пресингу, низької активності риби")
2. **Матеріали/конструкція → вигода** ("Верхнє коліно з карбону 24Т, комлеве з композиту —
   легка чутлива вершинка та міцний комель")
3. **Деталі оснащення → вигода** ("Легкі кільця не перевантажують бланк, рівномірно
   розподіляючи навантаження")
4. **Руків'я/зручність або застосування** ("Рукоятка з EVA, надійний гвинтовий котушкотримач")
5. (опц.) **Підсумок діапазону застосування**

ЗАБОРОНЕНО (зараз у нас це є — ВИДАЛИТИ):
- Однаковий абзац на весь каталог ("Перед покупкою варто звірити... менеджер магазину підкаже") — 7027 товарів!
- Рядок "Категорія каталогу: ..." — 6536 товарів
- Однаковий інтро для всієї сім'ї
- AI-кліше, довгі тире, надмірні списки

ТРЕБА: детермінована варіативність (пули фраз, вибір по hash(артикул)), вплітання реальних
параметрів у речення ("Довжина 2.51 м і тест 10-45 г — універсал для берегової ловлі").

## 4. SEO

### Title patterns
- Категорія: "{Категорія} — купити в Києві та Україні, найкращі ціни | {Магазин}" або "{Категорія} купити недорого - {Магазин}"
- Товар: "Купити {Назва} за низькою ціною. Відгуки, ціни, характеристики" або "{Назва} купити за {ціна} ₴ | {МАГАЗИН}"

### Meta description (категорія)
"{Категорія} для {призначення}. {ключові параметри/розміри}, обмін 14 днів, доставка по Україні."

### SEO-текст категорії (внизу сторінки, 2500-4500 знаків)
Структура з H2/H3:
1. Інтро-порада: чому правильний вибір важливий (1-2 абзаци)
2. "Види {категорії}" — H2 + розбір типів
3. "Як вибрати / на що звернути увагу" — H2 (матеріали, параметри)
4. "Чому купувати в {магазин}" — H2 (асортимент, ціни, доставка)
+ внутрішні посилання на підкатегорії та статті блогу

### Платформенні правила Horoshop
- SEO-шаблони метатегів: задати формули для категорій/товарів/брендів (1 раз — генерується для всіх)
- Хлібні крихти обов'язково; до товару ≤3 кліки
- alt для зображень товарів/банерів
- Блог → перелінковка на категорії (тематичні кластери), з категорій → на статті
